# Evidence catalog

Each phase retains a sanitized record of commands/tests, Azure observation timestamps, relevant run IDs, measured cost and cleanup status. Save a short `README.md` in its phase folder identifying every claim as **Planned**, **Implemented locally**, **Verified in Azure** or **Blocked**. Store screenshots only after redacting secrets, resource identifiers and sensitive context. Use relative links from the project walkthrough and case studies once verified.
